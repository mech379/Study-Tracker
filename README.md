# Study Tracker

A small command-line tool to log study sessions. Built to practice a Git/GitHub workflow
(branches, merges, conflict resolution, pull requests) for the Growing a Competency assignment.

## Usage
    python tracker.py add "Git basics" 45
    python tracker.py list

    python tracker.py total

## Git workflow used
- main + feature branches, merged with pull requests
- one merge conflict resolved manually
